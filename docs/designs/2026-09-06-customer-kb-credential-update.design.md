# 客户知识库首次绑定与换绑企业超管

## 目标

首次绑定时，使用客户知识库本地超级管理员账号和密码，通过绑定实例的受限成员接口创建同名企业超管；已有绑定再次提交时，将表单账号和密码视为目标实例的企业超管凭证，校验通过后才切换实例和服务凭证。

## 责任边界

- 云面板负责企业用户、密码哈希、`cp_membership.role=owner` 和成员身份登录。
- 客户知识库负责本地首次绑定授权、候选实例凭证校验以及加密保存当前服务凭证。
- 云面板已有 `POST /kb-instances/{instance_id}/members` 创建接口通过 `kb-bind-admin:` 幂等键把绑定创建的成员标记为 `owner`；不新增云面板接口。

## 主链路

### 首次绑定

1. 知识库确认当前没有有效的数据库或环境绑定配置。
2. 校验本地启用超级管理员账号和密码。
3. 使用候选实例 ID、服务凭证调用成员创建接口，提交本地账号、密码、姓名和知识库产品权限，并携带稳定幂等键。
4. 只有返回账号与请求一致且 `role=owner` 时，才加密保存服务凭证。

### 换绑

1. 发现已有有效绑定后，不再校验本地管理员，也不调用成员创建或成员更新接口。
2. 使用候选实例服务凭证读取成员目录，按账号查找目标企业成员并确认 `role=owner`。
3. 调用目标实例身份登录接口验证企业超管密码，并校验登录返回的账号、角色和成员 ID 与目录结果一致。
4. 所有远端校验成功后，才替换本地加密服务凭证和实例 ID；任一步失败都保留旧绑定。

## 失败边界与安全约束

- 服务凭证只在服务端请求头中使用，不写入日志、浏览器或响应正文。
- 首次创建远端账号成功但本地写入失败时，下一次使用相同幂等键重试，云面板返回同一绑定账号。
- 换绑的成员不存在、不是 `owner`、密码错误、身份返回不一致或目标实例未授权知识库时，不更新本地配置。
- 首次创建返回普通成员或格式不符合协议时，不保存本地绑定。

## 验收

- 无有效绑定时调用一次带 `kb-bind-admin:` 幂等键的成员创建接口，并保存返回为 `owner` 的绑定。
- 有效绑定存在时调用成员目录和身份登录校验，不调用 `POST` 或 `PATCH`，仅在验证成功后保存新配置。
- 换绑账号不是 `owner`、密码错误、成员不存在或远端失败时，旧加密凭证保持不变。
- 登录页在首次绑定和更新绑定两种状态显示不同的账号语义与成功提示。
